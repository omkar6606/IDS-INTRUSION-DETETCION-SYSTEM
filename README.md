# IDS-INTRUSION-DETECTION-SYSTEM

A Machine Learning-based Intrusion Detection System (IDS) developed using Python and the NSL-KDD dataset to detect malicious network activities and classify network traffic as normal or attack traffic.

## 📌 Project Overview

This project implements an Intrusion Detection System (IDS) using Machine Learning techniques for cybersecurity threat detection. The system analyzes network traffic data and identifies suspicious or malicious activities in real-time.

The project provides a complete pipeline, including:
- Data preprocessing
- Feature engineering
- Model training
- Intrusion prediction
- API integration
- Deployment-ready architecture

The system is designed to help Security Operations Centers (SOC) and cybersecurity analysts automate network threat detection and improve monitoring efficiency.

---

## 🚀 Features

- Machine Learning-based intrusion detection
- NSL-KDD dataset implementation
- Detects normal and malicious traffic
- REST API support using FastAPI/Flask
- Real-time prediction capability
- Data preprocessing automation
- Model serialization using Pickle
- Security-focused architecture
